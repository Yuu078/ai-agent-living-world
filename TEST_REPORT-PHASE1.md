## What was built
- **Monorepo** (npm workspaces): `shared/` (Section 5 event contract: `AgentState`, `WorldEvent`, `TaskPayload`, `GridMap`), `server/` (Fastify skeleton, `/health` only — full backend is Phase 2), `client/` (Vite + React 19 + TS strict + Tailwind v4 + three/R3F/drei + zustand; `socket.io-client` installed, wiring is Phase 2).
- **Campus**: 1-floor HQ — Reception, Open Workspace (6 desks), Glass Meeting Room (transmission glass), Coffee Corner, Lounge, Outdoor Garden (InstancedMesh trees, stone path, animated fountain, benches). Warm lighting, soft shadows, RoundedBox + PBR everywhere (no plain primitive boxes).
- **Cameras**: Isometric 3/4 (default), Free Orbit, Top-Down, Follow Agent — smooth lerped transitions; smooth wall/roof cutaway toggle (walls lower 2,8 → 1,05, roof lifts & fades).
- **6 articulated stylized avatars** (Nova, Kai, Rin, Mika, Sora, Bimo) with state animations: idle, walking (limb swing driven by walked distance), sitting, typing, thinking, coffee_break (+ meeting/tool_calling/celebrating/error poses ready for Phase 2/3 events). Movement exclusively via grid A*.
- **lifeSim**: local scheduler — desk work (typing/thinking with thought bubbles), coffee breaks, lounge sits, garden strolls, meeting-room syncs. Seat contention resolved by re-pick/fallback-to-desk.
- **Glassmorphism UI**: TopBar (world clock, active agents, honest `DEMO_MODE` chip — no fake LIVE toggle), Sidebar (agent list with live status, world shortcuts, locked Phase 2/3/4 features labeled as such), InspectorPanel (click avatar → state/zone/bubble detail), BottomDock (camera presets, cutaway, 1x/2x/4x speed).

## Known shortcomings (honest)
1. **No browser/WebGL verification** — rendering quality, Html label legibility, and animation feel are NOT TESTED (checks 6–7). Run `npm run dev` and open the client to eyeball before Phase 2.
2. **Bundle size** 1,18 MB JS (gzip 330 kB) in one chunk — acceptable for Phase 1; code-splitting belongs to Phase 4 performance work.
3. **Sitting pose** uses single-piece legs rotated forward (no knee joints) — stylized, consistent with the chibi avatar design.
4. **Destination cells are walkable by design** (chairs/seats/stands), so a passing agent could in theory route through an unoccupied chair cell; seats sit in low-traffic nooks and contention is handled, but a transient visual overlap is possible in rare crossings. It can never happen with walls/desks/tables/counters — those are true obstacles.
5. Server is an intentional skeleton (health endpoint only) per Phase 1 scope.
